# aio

Internal projects for blociapps.

## [`bls-hosting/`](bls-hosting) — BLS.Hosting

Self hosted bot hosting panel for the Windows VPS behind `blociapps.com`.
Zip upload with auto unpack, live console over websocket, environment and
secret management, per deployment RAM and port allocation, start / stop /
restart / kill, multi version Node and Python runtimes, access codes with
admin and viewer roles.

Install with `bls-hosting/setup.bat` on the server — see
[`bls-hosting/README.md`](bls-hosting/README.md) for the full walkthrough.
