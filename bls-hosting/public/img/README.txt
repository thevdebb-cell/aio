BLS.Hosting brand images

These five png files are the only images the panel loads. Everything else in the
interface  every button icon  is drawn by the code so it follows the dark and
light theme on its own and needs no file.

  bls-logo.png        portal header and panel top left  shown at 26 to 44 px
  intranex.png        portal tile 1
  bls-hosting.png     portal tile 2  also the access page header
  myorder.png         portal tile 3
  myspace.png         portal tile 4

What ships here are placeholders so nothing looks broken on a fresh install.
Overwrite them with your own artwork keeping the same file names.

  square  256 by 256 is ideal  128 also works
  transparent background so they sit well on both themes
  avoid pure black or pure white artwork  it disappears on one of the two themes
  a mid tone reads correctly on both

A missing file is not an error  the tile falls back to the first letter of its
name. The browser caches them for an hour so press ctrl f5 after replacing one.
